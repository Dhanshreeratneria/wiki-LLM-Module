# Deep Learning

Subfield of machine learning using multi-layer neural networks to learn hierarchical representations from data.

## Details

- Rose to prominence after the 2012 ImageNet breakthrough (AlexNet).
- Now spans vision, language, speech, robotics, and scientific applications.
