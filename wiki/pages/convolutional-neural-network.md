# Convolutional Neural Network

Neural network architecture using convolutional filters, well-suited to grid-like data such as images.

## Details

- LeNet and AlexNet were early landmark CNNs.
- Largely superseded by Vision Transformers for large-scale image tasks, though still widely used.
