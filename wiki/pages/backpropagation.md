# Backpropagation

Algorithm for computing gradients of a loss function with respect to network weights via the chain rule, enabling gradient-based training.

## Details

- Popularized for multi-layer neural networks in the 1980s, notably by Geoffrey Hinton and collaborators.
- Forms the core of virtually all modern deep learning training loops.
