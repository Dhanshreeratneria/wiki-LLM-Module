# Large Language Model

A Transformer-based model trained on massive text corpora to predict and generate language, exhibiting broad task ability.

## Details

- Scale (parameters, data, compute) strongly predicts capability, per empirical scaling laws.
- Examples include GPT-4, Claude, Gemini, and LLaMA.
