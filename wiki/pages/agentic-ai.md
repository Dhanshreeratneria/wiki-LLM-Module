# Agentic AI

Systems where an LLM plans and executes multi-step tasks using tools, memory, and environment feedback, rather than answering a single prompt.

## Details

- Claude Code and similar coding agents are practical examples.
- Raises new safety and reliability questions around autonomous tool use.
