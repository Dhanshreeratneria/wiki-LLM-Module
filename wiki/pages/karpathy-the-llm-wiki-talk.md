# Karpathy: The LLM Wiki Talk

Talk in which Andrej Karpathy describes the raw/wiki personal knowledge base pattern built with an LLM coding agent.

## Details

- Describes using Claude Code (or similar agents) to compile raw notes into a cross-linked markdown wiki.
- Argues this beats RAG/vector-DB setups for personal-scale knowledge management.
