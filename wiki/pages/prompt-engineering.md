# Prompt Engineering

The practice of crafting inputs to a language model to reliably elicit desired outputs.

## Details

- Includes techniques like few-shot examples, chain-of-thought cues, and explicit output formatting.
- Increasingly complemented by structured tool use and agentic workflows.
