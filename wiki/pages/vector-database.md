# Vector Database

A database optimized for storing and searching high-dimensional embedding vectors by similarity.

## Details

- Core infrastructure component for RAG pipelines and semantic search.
- Contrasts with the 'raw/wiki' pattern, which uses plain markdown instead of embeddings for personal knowledge bases.
