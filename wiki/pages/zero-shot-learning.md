# Zero-Shot Learning

A model performing a task with no task-specific examples, relying only on instructions.

## Details

- Modern instruction-tuned LLMs perform many tasks zero-shot with reasonable accuracy.
- Contrasts with few-shot prompting, which supplies examples.
